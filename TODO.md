    - Géolocalisation navigateur (gratuite) → Nominatim/OpenStreetMap pour le pays (gratuit, sans clé, limite 1 req/s, usage raisonnable) → classification de Köppen à héberger nous-mêmes en fichier de référence, sur le modèle de `country_capitals.js` — fiable et gratuit, aucune dépendance externe en continu

    - **Recherche menée le 21 août sur les services nationaux de sol** (pour évaluer une alternative à SoilGrids, par pays) — résultat : un seul pays sur les 4 déjà couverts a une vraie API exploitable.
      - 🇺🇸 USA : **SSURGO / Soil Data Access (USDA)** — API REST officielle, requêtes SQL, interrogation par coordonnées GPS, domaine public, aucune clé. Prêt à l'emploi.
      - 🇫🇷 France : GisSol/INRAE fragmenté — BDAT agrégée au canton seulement, arrêtée en 2014 ; référentiels régionaux (IGCS) distribués région par région dans des formats différents, pas d'API unique. Leurs propres serveurs signalent une coupure de maintenance (annoncée pour le 18 février 2026, plusieurs outils indisponibles : Donesolweb, Geosol, Refersols, Applicasol, Répédo).
      - 🇪🇸 Espagne : données régionales seulement (ex. Castilla y León via ITACyL) ; carte nationale existante mais en téléchargement statique, pas d'API par coordonnées.
      - 🇮🇹 Italie : carte des sols disponible via ESDAC (Commission européenne), en téléchargement statique, pas d'API live.
      - 🇪🇺 Europe transversal : **ESDAC/LUCAS** (Commission européenne) — plus de 70 000 échantillons harmonisés à l'échelle de l'UE, riche mais orienté téléchargement de jeux de données, pas requête en direct par coordonnées.
      - **Conclusion** : "une API différente par pays" ne fonctionne bien que pour les USA. Pour France/Espagne/Italie/UE, le vrai chemin serait de télécharger ces jeux de données une fois (LUCAS pour l'Europe, éventuellement les fichiers bruts SoilGrids — restent téléchargeables même API live en pause) et de les héberger nous-mêmes pour interroger localement, plutôt que de dépendre d'un service externe par pays — cohérent avec l'approche déjà retenue pour la zone climatique, mais un chantier d'infrastructure nettement plus lourd (rasters mondiaux, pas un simple fichier de référence).
